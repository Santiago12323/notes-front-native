# Design System

The application uses a centralized design system.

## Colors

All colors must be defined in:

src/theme/colors.ts

## Typography

Typography must be defined in:

src/theme/typography.ts

## Spacing

Spacing must be defined in:

src/theme/spacing.ts

## Borders

Border radius and border definitions belong in:

src/theme/borders.ts

## Components

Reusable components belong in:

src/components/

Examples:

- Button
- Text
- Icon
- Card
- Input
- Modal
- Header
- Divider

## Rule

Do not hardcode repeated visual values inside screens.

Use theme tokens.

## Design Philosophy

The UI should feel like a modern digital notebook.

Priorities:

1. readability
2. simplicity
3. touch usability
4. visual hierarchy
5. consistency
